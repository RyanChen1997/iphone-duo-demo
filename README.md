# Fold Studio

一个参考 iPhone Duo 折叠交互的独立演示页（非 Apple 官方作品）。手机居中，拖动滑杆可连续控制完整的 180° 开合；展开时屏幕是一张没有中缝的图片；折叠时左侧玻璃通过视线投影采样静止在右屏平面上的壁纸，画面不会随着面板旋转、压缩，且呈现渐进高斯模糊与轻微玻璃反光。阴影与虚化仅沿左侧玻璃的外缘渐变，右侧壁纸在开合中保持明亮；玻璃另一面也能透视固定壁纸，而超出原始壁纸矩形的上下区域为黑色玻璃，并与壁纸通过柔和虚化边缘衔接，不再出现硬分界或纯白镂空。接近合拢时外屏壁纸逐渐亮起。上传本地图片后会铺满展开的内屏；合上时外屏对图片居中裁切，不会压扁原图；可导出完整「展开 → 合上 → 展开」循环 GIF。

```bash
npm install
npm run dev
```

打开终端显示的本地地址。运行 `npm run build` 可生成生产构建。

- 图片与 GIF 均在浏览器本地处理，不会上传服务器。
- 接受常见图片格式，单张不超过 20 MB。
- GIF 为 640 × 440、72 帧、约 4.3 秒的循环动图。
- 3D 模型和默认风景画面由代码绘制，不使用 Apple 官方模型或素材。

# Fold Studio

一个参考 iPhone Duo 折叠交互的独立演示页（非 Apple 官方作品）。手机居中，拖动滑杆可连续控制完整的 180° 开合；展开时屏幕是一张没有中缝的图片；折叠时左半屏保留图片并呈现渐进高斯模糊与轻微玻璃反光，接近侧立时后方屏幕被短暂遮暗，随后外屏缓缓盖向右半屏。上传本地图片后会铺满展开的内屏；合上时外屏对图片居中裁切，不会压扁原图；可导出完整「展开 → 合上 → 展开」循环 GIF。

```bash
npm install
npm run dev
```

打开终端显示的本地地址。运行 `npm run build` 可生成生产构建。

- 图片与 GIF 均在浏览器本地处理，不会上传服务器。
- 接受常见图片格式，单张不超过 20 MB。
- GIF 为 640 × 440、72 帧、约 4.3 秒的循环动图。
- 3D 模型和默认风景画面由代码绘制，不使用 Apple 官方模型或素材。
